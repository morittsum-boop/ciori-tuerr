# カロリーチューナー v0.2（iPhoneホーム画面対応）

## iPhoneで使うには
1. このフォルダの中身をHTTPS対応の静的ホスティングに公開します（例：GitHub Pages）。
2. iPhoneのSafariで公開URLを開きます。
3. 共有ボタン →「ホーム画面に追加」→ 必要なら「Webアプリとして開く」をオン →「追加」。
4. ホーム画面のアイコンから起動します。

## 注意
- このZIPをiPhoneで開くだけではホーム画面アプリにはなりません。HTTPSの公開URLが必要です。
- 記録は今のところ、そのブラウザ／端末のローカルストレージに保存されます。端末間同期はありません。ブラウザデータ削除で記録が消える場合があるため、アプリ内のバックアップ機能を利用してください。
- 食事写真AI解析は接続先APIが未設定なら動きません。APIキーをHTML内に直書きしないでください。
- 歩数は現状手入力です。Appleヘルスケアからの自動取得には別途iOSアプリ／連携実装が必要です。
- 初回アクセス後は一部画面をオフラインでも開けるよう、Service Workerを追加しています。
